# Диагонали матрицы

## Назначение
Консольная программа сравнивает сумму элементов главной диагонали и сумму элементов побочной диагонали квадратной вещественной матрицы размерности n.

## Требования к окружению
- Python 3.10 или выше
- Git 2.30 или выше
- ОС: Windows 10/11, Linux, macOS

## Инструкция по запуску (предварительная)
1. Клонировать репозиторий: `git clone <URL>`
2. Перейти в каталог проекта: `cd matrix-diagonals`
3. Запустить программу: `python src/main.py`
4. Запустить тесты: `python -m unittest discover tests`

## Структура проекта
- `src/` — исходный код
- `docs/` — документация (техническое задание)
- `tests/` — тесты

## Стратегия ветвления
Используется упрощённый Git Flow:
- `main` — стабильная версия, всегда рабочая;
- `develop` — интеграционная ветка текущей разработки;
- `feature/*` — короткоживущие ветки под отдельную задачу, сливаются в `develop`.

Обоснование: проект небольшой, но учебный и командный по духу; `develop` защищает `main` от нерабочего кода, а `feature/*` позволяют вести задачи параллельно и изолированно.
