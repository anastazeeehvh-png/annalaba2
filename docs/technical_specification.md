# Техническое задание на программу «Диагонали матрицы»
(по ГОСТ 19.201-78, вариант 5)

## 1 Введение
Программа вычисляет и сравнивает суммы элементов главной и побочной диагоналей квадратной вещественной матрицы размерности n.

## 2 Основания для разработки
Учебное задание по дисциплине «Инструментальные средства разработки программного обеспечения» (ЛР №1, вариант 5).

## 3 Назначение разработки
Ввод матрицы n x n, вычисление сумм диагоналей, вывод результата сравнения.

## 4 Требования к программе
- размерность n — целое число от 1 до 100;
- ввод элементов построчно, корректность проверяется;
- вывод двух сумм и результата сравнения (больше / меньше / равны);
- Python 3.10+, консольный интерфейс.

## 5 Требования к программной документации
Техническое задание, README.md.

## 6 Порядок контроля и приёмки
